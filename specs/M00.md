# M00 基线与模块接口

原方案第一、四节。插件继续使用宿主原生会话、Worker 沙盒与 Python 单写入。公开插件仓库提供测试工具、脱敏样例和发行包。产品源码、Issue、PR 与 Release 记在各自的仓库。

产品以 GitHub 数字仓库 ID 为主键。版本是产品内的 `vN.N.N`。每个候选记录版本、提交、包摘要、DAG 摘要和纳入的 Issue 编号。一次实际运行记录请求标识和启动时解析的候选或稳定包摘要。发布和回退各有可重放的操作 ID。

在源码目录运行 `npm run verify:module -- M00`。这个任务覆盖原有 Python 与 Node 测试、模块测试、构建和发行包清单。通过 `AUTOLOOP_TEST_PYTHON` 可选择本机测试虚拟环境。单模块使用 `npm run verify:module -- M01` 等编号单独运行。Node 预览测试须在可绑定回环地址的环境执行。
