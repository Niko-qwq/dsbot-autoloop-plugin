# M07 发布与回退

由宿主校验 PM、产品仓库、发布目标与授权。发布操作先入账，再调用 GitHub 保存已冻结的版本和制品。独立核对 Release 的提交、制品和 DAG 摘要。默认入口按已确认的上一构建身份切换，并核对实际入口和新版本运行表现。入口验证通过后，逐条关闭该候选纳入的 GitHub Issue，最后生成可去重的发布事实。

回退需要匹配当前部署身份、同一目标的上一已验证构建及数据兼容依据。切换前可从入口控制面读回当前身份，即使当前构建运行失败也可在授权范围内切换。切换后核对恢复构建身份和运行表现，再生成回退事实。保留历史 Release、制品、DAG 快照和发布记录。

产品存储由单写入进程逐步持久化操作。GitHub 和入口适配器用操作 ID 与外部读回对账。丢失响应时可从最后持久化阶段恢复。如果默认入口已切换且发布验证失败，PM 可在授权内恢复到上一已确认构建。保留中断操作及 GitHub Release，Issue 继续开放。恢复核验通过后仅生成回退事实。

在插件目录运行 `npm run verify:module -- M07`。单独覆盖相同制品发布、读回后关单、响应丢失重放、入口身份漂移、运行验证失败、发布中断恢复和已发布构建的回退。
