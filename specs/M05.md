# M05 执行工作流和生成小工具

使用 Bot 提交小工具点子。宿主固定已确认的稳定版或被选中的候选版制品，加载并验证后交给 `run_workflow`。每次执行在专用目录生成可打开的 HTML 工具、使用说明、研究材料、可下载 ZIP 与制品清单。工具可离线使用。

V1 接受纯文本点子和结构化 `ToolBrief`。纯文本用工作流的默认工具类型与字段。结构化输入包含 `title`、`description`、`kind`、`labels`，可按类型附 `operation` 或 `template`。`kind` 需在工作流授权范围内。

- `research` 整理点子、选定的工具方案与制品内参考材料。
- `generate` 生成可交互的检查清单、计算器或文本模板。
- `validate` 核对浏览器入口、字段与内置脚本和样式。点子和标签作为文本处理。
- `package` 打包工具与说明，由 `manifest.json` 记录工作流、提交、DAG、点子和逐文件摘要。

`run_workflow` 只创建新的执行目录。宿主用 `verify_run_artifacts` 重新核对清单、工作流和各制品，再登记可验证的运行结果。运行结果可供 M06 评估试用。出品无法替代主观采纳的用户确认。

独立验收覆盖源目录删除后仍能按 A、B 各自制品生成不同工具、真实内置 JS 事件与结果、下载包内容、无效点子、覆盖和篡改拒绝。运行 `python -m pytest tests/modules/test_m05_workflow_runner.py`。安装验收另需通过使用 Bot 打开入口并操作工具。
