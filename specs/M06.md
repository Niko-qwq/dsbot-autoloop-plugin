# M06 候选试用与验收

每个产品同时选择一个冻结候选试用。候选固定仓库 ID、版本、提交、制品 SHA-256、DAG SHA-256 和纳入的 Issue 编号。暂停后保留原候选的全部试用回执。恢复时核对冻结身份。切换到另一份构建从该构建自己的计数继续。

使用 Bot 由宿主选择候选制品执行真实任务。宿主记录运行 ID、任务及证据引用、实际制品摘要和执行模式。候选运行使用只读、演练或隔离模式。每个运行 ID 绑定一份回执，重复回传同一内容只记一次。

客观检查由宿主规则核验，需要主观判断的结果由授权用户确认。收到回执后先等核验。通过的不同运行达到三次，PM 才能提交发布。发布开始后锁定这份试用记录。

Chief 的认证客户端可以提交 `check_trial`，以真实运行 ID、候选 ID 和运行前确定的工具类型、字段与输入输出用例发起规则核验。插件重新读取并校验运行制品，实际执行浏览器工具脚本和核对结果，匹配后保存 `rule` 回执与证据摘要。失败或重复操作保持原有计数。

在插件目录运行 `npm run verify:module -- M06`。单独覆盖同构建三次验收、重复回传、不同摘要、失败和待核验、切换后归零、恢复后继承计数及运行模式校验。
