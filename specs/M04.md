# M04 冻结工作流制品

PM 验收对应的 Git 集成提交后，宿主从该提交的 Git blob 读取 `workflow.json` 和列出的参考材料，将准确的提交 SHA 与版本 DAG 快照写入冻结 ZIP。候选制品、归档和发布共用同一份 ZIP 字节。运行时从 ZIP 读取工作流，校验 SHA-256、提交与 DAG 摘要。工作区的后续改动不影响已有制品。

Worker 在产品仓库根目录交付 `workflow.json`。最小示例如下。

```json
{
  "schema": 1,
  "title": "小红书创作检查工具工厂",
  "steps": ["research", "generate", "validate", "package"],
  "tool": {
    "kind": "checklist",
    "labels": ["确认目标受众", "核对参考来源", "图片有说明"]
  },
  "allowed_kinds": ["checklist", "calculator", "template"],
  "resources": []
}
```

`allowed_kinds` 可省略，默认只允许 `tool.kind`。计算器支持选填的 `operation`，值为 `sum`、`average` 或 `product`，默认求和。模板工具支持选填的 `template`，用 `{1}` 等编号引用 `labels` 中的字段。可声明 `resources/` 下的 UTF-8 `.md`、`.txt`、`.json` 文件。根目录下未声明的路径不会进入制品。V1 内置能力语义随 schema 版本维护。

宿主从本地 Git 对象读取集成提交，或从 GitHub 读取该提交的文件并和已验收快照逐字节核对。冻结接口返回字节、制品摘要、提交和 DAG 摘要。`load_workflow` 校验摘要和规范包的条目名称、类型、大小及 DAG 身份。

独立验收覆盖可复现字节、提交与 DAG 关联、工作区改动隔离、非法能力、路径、符号链接和篡改包。运行 `python -m pytest tests/modules/test_m04_workflow_package.py`。
